# PocketTrack

## Problem Statement

Many college students struggle to track their expenses, manage monthly budgets, and understand their spending habits.

PocketTrack is a web-based expense tracking system designed to help students organize expenses, monitor spending categories, and improve financial awareness.

---

## Functional Requirements

1. Users can create an account.
2. Users can log in securely.
3. Users can add expenses.
4. Users can categorize expenses.
5. Users can view monthly summaries.
6. Users can edit or delete expenses.

---

## User Stories

1. As a student, I want to track my expenses so that I can manage my budget better.

2. As a student, I want to categorize expenses so that I can understand where my money goes.

3. As a student, I want to see monthly spending summaries so that I can avoid overspending.

## Main Screens

1. Login Page
2. Register Page
3. Dashboard
4. Add Expense Page
5. Expense History Page
6. Monthly Summary Page

---

## User Flow

1. User creates account
2. User logs in
3. User accesses dashboard
4. User adds expenses
5. User views expense history
6. User checks monthly summaries
